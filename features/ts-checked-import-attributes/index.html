TypeScript change

Checked import attributes and assertions

Status
Behavior changeBreaking change
Release
TS 5.4
Compiler released
2024-03-06

Import metadata is checked against the global ImportAttributes type.[2]

What it does

Hosts and libraries can augment ImportAttributes to restrict supported keys and values. Static imports and assertions that do not satisfy that interface now produce type errors.[2]

Before / after

Migration

Correct the attribute value or augment ImportAttributes with the metadata accepted by the target runtime.[2]
