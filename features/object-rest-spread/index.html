Object rest and spread properties

Also known asRest/Spread Properties, Object rest/spread properties

Status
Standardized
Proposal stage
Stage 4
Edition
ES2018
Reached Stage 4
2018-01-23
Standard published
2018-06-27

Object literals accept ...source to copy properties in, and object patterns accept ...target to collect the properties they did not name.

What it does

The object initializer grammar gains PropertyDefinition : ... AssignmentExpression.[4] Evaluating that production calls CopyDataProperties on the object under construction with an empty exclusion list.[5] CopyDataProperties walks [[OwnPropertyKeys]], skips any key whose own descriptor is not enumerable, and installs the rest with CreateDataProperty; a source of undefined or null leaves the target untouched.[6]

ObjectBindingPattern gains a BindingRestProperty alternative, both alone and after a property list.[7] RestDestructuringAssignmentEvaluation creates an object with %ObjectPrototype% and copies into it every property except the names the pattern already bound.[8] The proposal frames the pair as the object counterparts of array rest elements and array spread elements, and names the rest form's job as collecting the remaining own enumerable keys the pattern did not pick off.[1][2]

Before / after

Gotchas

Spread is not Object.assign with new syntax. CopyDataProperties installs each property with CreateDataProperty, while Object.assign writes through Set, so an inherited setter on the destination runs in the second case only[6][9]:

Both forms read own properties only, so { ...Object.create({ base: 1 }) } is {}; the proposal calls this out as the reason a spread is not a general clone.[3] A rest target always receives a plain object: Object.getPrototypeOf(rest) === Object.prototype holds even when the source had another prototype, because the evaluation step passes %ObjectPrototype% to ObjectCreate.[8] Spreading a string spreads its index properties, so { ..."hi" } is { "0": "h", "1": "i" }.

Support

V8 shipped both halves in 6.0, whose examples destructure with a rest binding and rebuild the object with a spread.[11]
